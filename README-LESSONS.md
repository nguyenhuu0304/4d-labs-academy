# Interactive lessons v0.3.0

- 6 modules, 24 clickable topics with bilingual long-form explanations, examples, key takeaways, whitepaper section references.
- Topic completion is stored in browser localStorage (`4d-academy-read-v1`), not in Discord/cloud.
- Existing quiz, certificates and Discord login remain.
- OAuth fix: Discord issuer is explicitly https://discord.com.
- Whitepaper source: 4D Labs Whitepaper V1.0.
- The docs link points to official docs landing page; section citations refer to the whitepaper and do not imply every proposed product is live.

To run: copy your own .env.local from v0.2.0 (do not share it), npm install, npm run build, npm run dev.
