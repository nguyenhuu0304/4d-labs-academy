# 4D Labs Academy · Community prototype v0.1.0

Independent educational project, NOT an official 4D Labs product. No token, NFT, official role, or financial rewards are promised.

## Run on Windows PowerShell

```powershell
cd "D:\Projects\4DLabs\4D-Labs-Academy-v0.1.0-ready"
npm install
npm run check:bank
npm run dev
```

Open http://localhost:3000.

## Scope
- 6 modules, 60 candidate questions (10/module), bilingual lesson overviews.
- 15 randomized questions, 15 seconds per question, pass >=12/15.
- Immediate answer review with source links; browser-local progress.
- Downloadable PNG certificate, X Intent with prefilled text (attach downloaded PNG manually).
- This is a LOCAL DEMO. Results and certificates are NOT server-verified; browser storage can be modified. No shared leaderboard, Discord login, or admin panel in this version. These require secure server/database infrastructure.

## Important content caveat
The 60 candidate questions have structural validation but have NOT been fully independently checked against each whitepaper section and the latest docs. Review before publishing or giving rewards. Questions are deliberately educational rather than official claims of product availability.
